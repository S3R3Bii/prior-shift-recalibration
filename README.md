# Can a cheap probability correction replace a coefficient refit?

**Work in progress.** The protocol, exact source panels and independently checked fitting code are available. No test result is claimed in this revision. This study compares probability adjustments with a fixed-penalty coefficient refit when the target event prevalence is supplied as an experimental input.

The practical question is whether a team can adapt existing probability scores without refitting every feature coefficient. This is a controlled benchmark experiment, not measured production drift, a novel calibration algorithm or a production service. MAGIC is Monte Carlo simulation; MiniBooNE is a public event-identification benchmark. Neither supplies a measured deployment prevalence here.
